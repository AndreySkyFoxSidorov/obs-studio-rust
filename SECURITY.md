# Security policy

SkyLive is an experimental project. Security reports about this repository are welcome; support and response times are not guaranteed.

## Reporting a vulnerability

Please do not disclose exploitable details, credentials, stream keys, or personal data in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**. Otherwise, contact the repository owner privately using a contact method available on their GitHub profile. If no private contact method is available, open a public issue asking for a private reporting channel without including vulnerability details.

Include the affected revision, platform, impact, and safe reproduction steps. Test only systems and accounts you own or are authorized to test; avoid accessing other people's data or disrupting services. Coordinate disclosure with the maintainer and allow reasonable time for investigation and a fix. Reports about OBS Studio itself should follow the [OBS Studio security policy](https://github.com/obsproject/obs-studio/security/policy), not this project's policy.
